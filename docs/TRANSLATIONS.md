# Sprachen und Übersetzungen (LP-30)

Die Oberfläche bietet einen Sprachschalter Deutsch/Englisch. Die Einstellung bleibt im Browser gespeichert und bestimmt die gewünschte Sprache neuer Lernsitzungen. Eine bereits gestartete Sitzung behält ihre ausgewählten Fassungen; für eine andere Sprache eine neue Sitzung beginnen.

Eine veröffentlichte Frage hat eine Originalsprache. Im Bereich **Fragen übersetzen** wird eine vollständige Sprachfassung für Deutsch oder Englisch erstellt. Sie umfasst jeden Textblock der Frage, alle Antwortblöcke, jeden Erklärungsblock und die Bildbeschreibungen. Bilder bleiben dieselben privaten Medienobjekte. Die API akzeptiert nur dieselbe Reihenfolge, dieselben Blockarten und Medien-IDs wie in der zugrunde liegenden Frageversion. Übersetzte Antworten sind über `optionId` fest an die ursprünglichen Antwortoptionen gebunden. Das Korrektheitsmerkmal wird nie als übersetzbares Feld übernommen; die Benotung verwendet stets die unveränderten Originaloptionen.

`POST /api/v1/questions/{id}/versions/{number}/translations/drafts` legt eine neue private Revision an. Jede Revision dokumentiert Herkunft, Lizenz, Entstehung (`manual` oder `ai-assisted`), Autor und Zeit. Erst `POST .../{translationId}/approve` mit ausgefüllter Herkunft und Lizenz gibt diese Revision frei. Bereits freigegebene Revisionen bleiben zur Nachvollziehbarkeit erhalten. Für eine Korrektur wird aus dem Verlauf ein neuer Entwurf gespeichert und separat freigegeben. Ein älterer Entwurf kann eine neuere Freigabe nicht überschreiben. Der Verlauf zeigt dem Eigentümer gemeldete Fehler; Meldungen über `POST .../{translationId}/reports` beziehen sich auf die konkrete freigegebene Revision.

`GET .../{language}` liefert die jüngste freigegebene Fassung. Fehlt sie, enthält die Antwort das Original mit `missing: true`; das Lern-UI kennzeichnet diesen Fall sichtbar. Beim Start einer Sitzung wird die ID der freigegebenen Revision im Sitzungsplan fixiert. Ein späterer Korrekturstand verändert laufende Sitzungen nicht und beeinflusst keine richtigen Antwort-IDs.

Eine KI-Übersetzung ist optional. Nutzende wählen einen konfigurierten Anbieter ausdrücklich und bestätigen die Übermittlung des Originaltexts und der Bildbeschreibungen. Bilddateien und Kontodaten werden nicht gesendet. Der Provider muss strukturierte Chat-Completion-Antworten unterstützen; sein Vorschlag wird auf vollständige Felder und unveränderte IDs/Medien überprüft und bleibt im Browser bis zur Bearbeitung und Speicherung. Quoten und Größenlimit entsprechen den vorhandenen optionalen KI-Modi. Eine KI-Ausgabe wird niemals automatisch freigegeben. Für die fachliche und rechtliche Prüfung jeder Übersetzung bleiben die Nutzenden verantwortlich.

Die Datenbankmigration `20260929210000_QuestionTranslations` legt die Revisionen und Fehlermeldungen an. Bestehende Fragen bleiben in ihrer Originalsprache lesbar.
