# LearnPip licensing scope

This page describes the intended scope of the licenses used by LearnPip. It does not transfer ownership of third-party or user content.

| Material | License or rights |
| --- | --- |
| LearnPip program code that is explicitly part of the software | GNU AGPL-3.0-only, identified in [LICENSE](../LICENSE) and in applicable source-file notices. The license grants the rights stated in its complete text. |
| Documentation, screenshots, and other non-code material | Not automatically covered by the software license. Each item needs its own notice before reuse is invited or permitted. |
| User-created questions, answers, explanations, photos, and uploads | Remain subject to the rights of their creators and any permissions they expressly grant. Submitting material does not by itself assign it to LearnPip or place it under AGPL. |
| Third-party libraries, fonts, icons, images, and other included components | Governed by their own license or terms. Record notices and comply with each component's conditions; this project's LICENSE does not relicense them. |
| LearnPip name, logo, and visual identity | No trademark or endorsement rights are granted by the software license. |
| Public question pool, when implemented | Requires an explicit content-license choice and a clear grant from the person who has the necessary rights before publication. This is separate from the code license. |

## Commercial licensing

The AGPL permits commercial use when its terms are followed. An optional separate commercial license may be offered for software rights the project can license on those terms. It cannot cover third-party material or contributor work unless the necessary rights have been obtained.

The individual and entity CLAs are currently drafts for legal review, not active agreements. Until a reviewed agreement is published and accepted by a contributor, do not assume the Project can sublicense that contributor's code under additional commercial terms. See [CONTRIBUTING.md](../CONTRIBUTING.md) and the [CLA rollout checklist](CLA-ROLLOUT.md).

A separate commercial license does not remove the public AGPL release of the corresponding official project code.

## Source link for hosted versions

The repository currently contains no running software. Before a network-operated LearnPip release is made, the product should display a link to the corresponding source revision and its license. The link should identify the source code for the version the operator is actually running, not merely the newest repository branch.
