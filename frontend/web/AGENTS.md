# Änderungen an der Weboberfläche

Bei Änderungen an Oberfläche, Texten, Assets oder Build-Abhängigkeiten die
Dokumentationsbilder mit `npm run docs:screenshots` aktualisieren.
Alle vier Bilder visuell prüfen und mit `docs/screenshots/manifest.json`
einchecken. `npm run docs:screenshots:check` muss erfolgreich sein.
Anleitung und Galerie: [Bildvorschau](../../docs/UI-PREVIEW.md).

Jedes Dokumentationsbild braucht einen aussagekräftigen Alternativtext.
Bei Änderungen am gezeigten Inhalt auch die Bildbeschreibung aktualisieren.
